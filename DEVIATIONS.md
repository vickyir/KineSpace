# Deviations from Figma

Figma (file `4SCv02YIheXVRsWneQyKwg`) is the source of truth for layout, copy, colour, hierarchy and sizes. Where it conflicts with a Spectacles platform rule, the platform wins and the closest equivalent is built. Every such case is logged here, including conflicts inside Figma itself.

Status: **Done** = implemented and checked in the preview · **Done (dev)** = development tool only, off in release · **Accepted** = approved trade-off, no further work · **Watch** = to measure on device ([`Docs/DEVICE_TEST_CHECKLIST.md`](Docs/DEVICE_TEST_CHECKLIST.md)) · **Open** = built as described, waiting for a designer or physiotherapist decision.
